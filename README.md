# 旅途手帖

公开网址：https://yespsam.github.io/hokkaido-travel-preview/

GitHub Pages 独立旅行工具，电脑关机仍可访问。

支持四套起步方案、本机方案快照及整库导入导出；32条内置地点／目的地资料和自建地点；加入活动或新增一天；预算联动、预约记录、通用待办、离线 HTML；Open-Meteo 城市搜索、天气和日出日落。

资料当前以日本为重点。当前 cloud-config.json 留空：行程与方案库只保存到此浏览器，实际 Supabase 尚未连接。分享网址不会携带本机修改。航班／酒店实时库存、小红书／大众点评实时评论、后台交通推送尚未接入；网页的数据状态页明确区分这些能力。

源码与部署分开保存，此仓库仅包含公开资料和编译资源，不含数据库密码或个人订单。图片来源见网页及 spots/SOURCES.md。
